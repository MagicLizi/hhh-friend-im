# 阅读状态

2026-10-29，用户确认范围包括 Cindy IM 客户端和服务端。沿用 HHH 已有的回执、写回、回读三项能力与消息旁的现有界面。

阅读位置由设备签名，使用独立派生的会话密钥加密。服务器保存每个账号、会话、设备的最新密文和 CAS 版本，看不到读到了哪一条；客户端核对签名、成员身份、消息归属与精确序号，合并各设备最大的有效位置。阅读记录独立于聊天，不出现为消息，不影响会话排序或新消息通知。

同一设备重置账号身份后，不继承旧身份的阅读边界；数据库按账号和设备保存的 CAS 版本仍连续递增，避免新身份的第一次写入永久冲突。

重置后已经丢弃的旧密钥不再尝试恢复。旧阅读信封仍核对成员与设备签名，公开版本号只用于 CAS；无法解开的历史阅读边界保留未知，不阻断新身份的阅读写入与回读。已持有密钥时的解密或验签失败仍报错，不能降成未读。

服务器在登录回执里声明可选阅读扩展，旧服务器缺省不支持，新客户端保留聊天。新通知只交给主动订阅读取的连接，旧客户端不收到新事件。断线和重启后重新查询服务端记录。未知写入不自动重放。

服务器新增独立阅读表及索引，仍由 Store 管理，原有表和格式保持不变；SQLite 完整备份覆盖新表，降级旧服务器会保留新表、暂停阅读扩展，升级后继续使用。客户端和插件不新增本机聊天库或凭据副本。

回执名单按消息发送时的已验证成员区间确定收件人，不以当前群成员拼凑历史分母。没有阅读记录的旧客户端收件人保持未知，不能把“未报告”冒充明确未读，也不把已确认名单的长度当成完整已读人数。分页、有界查询、无变化零写入、错误与跨账号隔离均纳入验收。
