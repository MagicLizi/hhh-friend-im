# 阅读状态

2026-10-29，用户确认范围包括 Cindy IM 客户端和服务端。沿用 HHH 已有的回执、写回、回读三项能力与消息旁的现有界面。2026-11-02（friend-im v10）起服务器不再保存已读，改为设备之间交换。

阅读位置由设备签名，使用独立派生的会话密钥加密。位置是消息的排序键（发送方签的时间 + 消息编号），不再是服务器日志序号。每台设备在内存里记每个会话、每台设备最新的一份，版本取 `max(现在, 上一个版本 + 1)`，乱序到达时留版本最大的；客户端核对签名、成员身份与消息归属，合并各设备最大的有效位置。阅读记录独立于聊天，不出现为消息，不影响会话排序或新消息通知。

记录只在内存：设备上线、对账时把手里的记录交给有权的设备（`PeerFrame::Reading`），插件重启后从在线的设备补回，补回之前保持未知。服务器和宿主都不存这些记录；宿主里的本机已读位置照旧由宿主自己管。

同一设备重置账号身份后，不继承旧身份的阅读边界。重置后已经丢弃的旧密钥不再尝试恢复：旧阅读信封仍核对成员与设备签名，无法解开的历史阅读边界保留未知，不阻断新身份的阅读写入与回读。已持有密钥时的解密或验签失败仍报错，不能降成未读。

回执名单按消息发送时的已验证成员区间确定收件人，不以当前群成员拼凑历史分母。没有阅读记录的收件人保持未知，不能把“未报告”冒充明确未读，也不把已确认名单的长度当成完整已读人数。分页、有界查询、无变化零写入、错误与跨账号隔离均纳入验收。
