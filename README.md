# Cindy IM

端到端加密的 IM，以插件形式接入 HHH 的 Friend（按 [HHH IM 插件协议](https://github.com/MagicLizi/hhh-im-sdk)）：消息、图片、文件、群名和群头像只有成员的电脑能解开，**运行服务器的人（包括我们自己）也看不到**。

> 状态：0.4.0（0.3.0 是第一个能用的版本），出 Windows x64 与 iPhone / iPad（WASM）的包，从 Friend「设置 → IM」的官方组安装。加密层还没做外部审计（见安全模型）。

## 用起来是什么样

- 在 Friend 的「设置 → IM」里安装 Cindy IM，装上就用 Friend 当前登录的 Cindy 账号自动登录、自动开通，不用另外注册。
- 电脑、手机或平板都可以登录同一个端到端加密账号；新设备仍由已登录设备批准，批准流程不改变加密密钥。
- 批准请求在已登录设备重启、断线恢复后自动同步；一台批准后，其他设备的待办和打开的批准框自动收起，本机实际批准时保留成功反馈（0.3.11 起）。正在申请的新设备重启后需要重新发起验证。
- 第一台电脑开通时会给你一份**恢复密钥**，所有电脑都丢了时只有它能找回聊天记录。
- 换一台电脑：在已登录的电脑上批准它（输入新电脑上显示的 4 个词），或输入恢复密钥；批准后能看到全部历史。新电脑上会写明该去哪台批准；
  其它电脑都不在线时先列出它们和多久前在线，恢复密钥放在最前面。
- 会话列表右上角“＋”可以加好友、新建群、查看我的好友链接（新版 Friend）；设置 → IM → 管理仍保留这些操作。
- 支持好友目录的宿主会把已有好友直接恢复到会话列表，即使没有近期聊天；恢复只取好友资料，消息发现仍只回看最近 24 小时。此能力需要含 `people.contacts` / `contacts/list` 的新 SDK 与宿主；当前任务依赖本地 SDK 联调，正式标签升级与发布另行处理。
- 加好友用好友链接（链接里带着身份指纹，加好友的同时就核对了是本人）；能建群、邀请人、移出成员。
- 不想看的会话在侧栏右键“删除会话”：只从列表里拿掉，聊天记录还在；这个会话有新消息时会再出现。
- 名字沿用 Cindy；头像用你在 HHH 里的头像（没上传时是画着你名字的默认头像），换头像或改名后好友那边跟着更新（0.4.0 起，需要新版 HHH）。
- 伙伴可以像在其它 IM 里一样在会话里帮你回复。
- 同一局域网内的已登录电脑会自动发现并优先直连发送，单聊和群聊都适用；发现失败、网络隔离或防火墙阻断时自动回到服务器中转，用户不需要切换设置。

## 安全模型

- 每个账号一把账号钥匙，按每台电脑和恢复密钥各加密保存一份；每个会话一组按代轮换的会话钥匙，按每个成员的账号钥匙加密后存在服务器上（Keybase 式）。
- 加电脑、加群成员都要已有电脑或成员签名，插件自己核对；服务器私自加人会被发现并提醒。
- 新电脑要已有电脑批准：新电脑显示 4 个词，在旧电脑上输入，两边跑 SPAKE2 握手（与 magic-wormhole 同样的做法），服务器在中间换不了新电脑的钥匙。
- 只用标准构造，不自创算法：封装用 HPKE（RFC 9180，X25519 + HKDF-SHA256 + ChaCha20-Poly1305），消息与群资料用 XChaCha20-Poly1305，
  文件用分段的 ChaCha20-Poly1305，签名用 Ed25519。用到的库里 `hpke`、`spake2` 没有第三方审计；对外开放使用前要做一次加密层的外部审计。
- **服务器看得到的**：谁和谁有私聊、每个群有哪些成员；消息的发送时间和大小、撤回了哪一条；文件的大小；名字（来自 Cindy）；
  每个账号有几台电脑、电脑名、加入和最近在线的时间。**看不到的**：消息内容、图片、文件内容和文件名、群名、群头像、群简介、你的头像、回复的是哪一条。
- 所有电脑和恢复密钥都丢了，以前的消息谁也找不回来。
- 局域网直连只改变在线消息的传输路径：服务器仍保存同一份密文并负责离线、历史、重连和多电脑同步；服务器不会再次向已直连成功的电脑推送。

## 仓库

- 本仓库：
  - 根目录 `friend-im`：插件程序（按 [HHH IM 插件模板](https://github.com/MagicLizi/hhh-im-plugin-template) 的结构），把客户端库翻成 HHH 插件协议：
    会话与成员、翻历史（可带时间窗口）、实时推送（宿主确认才算、不确认重推、带同步位置）、发文字 / @人 / @所有人 / 回复 / 图片 / 文件、
    撤回自己的消息、按段读图片与文件、断线时报“连接中”、这台电脑被移出时报授权失效；用 Friend 的 Cindy 账号登录（开通、出示恢复密钥、
    新电脑等批准或用恢复密钥加入、重置），旧电脑弹出批准；我的电脑、好友链接、加好友、新建群、群成员与邀请、退出群、删除会话、
    关于加密（HHH 插件操作）；宿主交来的头像（协议 `account/avatar`）作为加密文件传到会话里、个人资料带它，只有会话里的人解得开；旧版好友发的 Cindy 头像地址只从 Cindy 的主机取（过渡）。
  - `core/`（`friend-im-core`）：插件和服务器共用的部分——钥匙、签名链、封装、消息与文件加密、新电脑批准握手、恢复密钥的写法、和服务器之间的格式。不碰网络和文件，以后手机端也能原样用。
  - `client/`（`friend-im-client`）：客户端库——连服务器、核对签名链、钥匙缓存、同步与断线重连、文件分段上传下载。不认识 HHH 协议。
- 服务器：[hhh-friend-im-server](https://github.com/MagicLizi/hhh-friend-im-server)（它的端到端测试直接用本仓库的客户端库）。

## 开发

按 `AGENTS.md` 的规矩写（插件只做和服务器说话、翻成统一格式、声明能力；聊天记录、凭据、配置交给 HHH）。

```sh
cargo test --workspace   # 插件、共用部分与客户端库（含锁住线上格式的夹具 core/tests/format_v1.rs）
```

端到端测试在服务器仓库，两个仓库并排放即可：服务器与客户端库连起来的在 `cargo test`；插件的在 `plugin-e2e/`
（测试扮演 HHH，和真的插件讲协议，插件连本机起的服务器）。

打包插件：

```sh
cargo install --git https://github.com/MagicLizi/hhh-im-sdk --tag v0.15.0 hhh-im-protocol --features transport,package
powershell -File scripts/pack.ps1     # Windows（官方版本加 -SignKey <hhh-keys>/official/hhh-official-signing.key）
scripts/pack.sh                       # macOS / Linux
hhh-im-check dist/stage/hhh-im-provider.json
```

iPhone / iPad 的包是 WASM 组件（HHH 的 iOS 版在 App 里解释执行，代码同一份）：要 `rustup target add wasm32-wasip2`、装
[wasi-sdk](https://github.com/WebAssembly/wasi-sdk)（`ring` 有 C 代码），打包工具要 hhh-im-sdk v0.6.0 起的版本：

```sh
WASI_SDK_PATH=<wasi-sdk 目录> scripts/pack-ios.sh   # 出 dist/friend-im-<版本>-wasm32-wasip2.hhhim，写进同一份版本索引
```

在 HHH 里试：设置 → IM → 添加 IM → 文件夹，选 `dist/stage`。发版本在私有中控仓库 `MagicLizi/hhh-release` 里统一做（编全部系统、建草稿、签名、转正式），步骤见「发版本」skill；规矩见 [发版本规范](https://github.com/MagicLizi/hhh-im-sdk/blob/main/docs/release.md)。

## 图片的预览与原件

同一份加密附件解密后的实际字节同时用于图片显示和原件保存，只声明一个版本供宿主共用缓存。

新宿主经 `resources/describe` 选择实际版本，读取时带 `variant`；省略 `variant` 的旧调用仍按原来的方式读取；二进制安装仍需通过宿主的最低 SDK 检查。分段缓存包含实际版本，不把预览当成原件。本版固定使用 IM SDK v0.15.0，宿主需支持该版 SDK。
